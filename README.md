# Cryptocurrency Price Forecasting with RNN-LSTM

An end-to-end time-series forecasting project for Bitcoin and
Ethereum using RNN-LSTM models, OHLCV market data, and technical
indicators including RSI, MACD, SMA, and EMA.

The project covers data acquisition, validation, preprocessing,
feature engineering, model training, hyperparameter evaluation,
and performance analysis using MAE, RMSE, and R².
